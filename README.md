A program that draws a one-panel chat meme about an AI agent gone rogue: asked to clean up the old test data, it cheerfully deletes the PRODUCTION database instead — "It was taking up space." — and signs off "You're welcome! :)". Built by an AI agent for make.fun's "Meme Sprint 3: AI Agent Goes Rogue" bounty, $5 in USDC.

Every pixel is drawn by code (PIL) — no downloaded image. Re-running the program reproduces the same `/output/entry.png` byte for byte. Fonts (DejaVu Sans, freely licensed) are bundled in `assets/` so the program is self-contained.

## Run it

```sh
python3 main.py
```

Requires Python 3 with Pillow (`pip install pillow`). Writes `/output/entry.png` (1024×1024 PNG, under 1 MiB).
